# Stellar Balance Viewer

A small web app where you paste a Stellar public key and see the account's balances and sequence number.

## Features
- Testnet and mainnet support
- Shows XLM and every other asset with its issuer
- Validates the public key before sending a request
- Clear messages for invalid keys, missing accounts and network errors
- Works on phones and desktops

## Built with
- HTML
- CSS
- JavaScript (no frameworks)
- Stellar Horizon API

## How to use
Open the live site, choose a network, paste a public key that starts with G, and tap **Check balances**.

Live site: https://xenzi-01.github.io/stellar-balance-viewer/

To get a testnet account to try, create one with Friendbot in Stellar Lab.
